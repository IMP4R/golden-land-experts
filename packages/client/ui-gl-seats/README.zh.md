# @deepseek-ai/dsh-client-ui-gl-seats

[English](README.md) | 中文

Golden Land 在 DeepSeek Harness Web 外壳中的浏览器界面。

该包向 `sidebar.footer.action` 提供一个占用项，并根据侧边栏的展开或窄栏状态渲染 `Проекты` 与 `Дизайн` 两行。

`Проекты` 打开由 `http://127.0.0.1:3181/api/projects` 提供数据的本地弹出面板。`Дизайн` 以较低优先级临时遮蔽 `details` 插槽，因此面板复用原生详情列、拖动手柄、宽度让步算法和关闭生命周期。释放遮蔽后，内置工具详情占用项会恢复。

## 模型体验

无，因为浏览器侧的 Golden Land 导航和预览界面不注册任何模型可见内容。

#### KV 缓存影响

无。仅浏览器状态不会进入模型历史。

## 已知限制与延期工作

- **会话作用域的设计面板** — 当前会话为空时，`details` 的会话作用域使 `Дизайн` 行保持禁用。
- **本机服务依赖** — 项目注册表和设计目录依赖 3181 端口上的 Golden Land ledger 服务。
- **项目只读** — 项目弹出面板不修改注册表；项目变更仍由工具负责。
